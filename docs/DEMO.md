# 통합 데모 (자동 생성)

> 이 파일은 `adgate docs` 가 `artifacts/demo_*.json` 에서 만든다. **손으로 고치지 않는다.** 산출물은 `adgate demo --out artifacts/demo_offline.json`,
> `adgate demo --mode recorded --variant haiku --out artifacts/demo_recorded_haiku.json` 처럼 만든다.

**이것은 데모이지 측정이 아니다.** 각 모듈의 수치는 사전등록 평가(`EVAL_*.md`)가 낸다. 여기서는 모듈 *사이의 이음새* — 한 모듈의 출력이 다음 모듈의 입력이 되는 곳 — 에서 무엇을 검사하는지가 전사(transcript)와 이음새 검사로 남는다. 광고주 한 사람의 흐름은 이렇다: 대화로 캠페인을 만들고 → 상품 페이지에서 소재를 만들고 → 광고주가 쓴 문구를 심사하고 → 집행 중 소재 하나가 반려돼 성과가 꺾이면 원인을 진단해 '반려 소재 수정'을 권하고 → 그 수정을 심사의 수정안으로 잇는다.

모드: **offline** 은 모델 없이 결정론이다 — 광고주 발화의 추출은 *정답을 그대로 돌려주는 오라클*, 소재 생성은 정답 사실을 이은 대역이라 그 문장은 모델이 쓴 것이 아니다(게이트가 같은 입력에 같은 판정을 내는지 보이는 용도). **recorded** 는 실호출 녹음을 재생한다 — 같은 에이전트·같은 게이트 안에 *실제 모델이 낸 응답*이 들어간다. 녹음이 없는 단계는 '녹음 없음'으로 드러내고 조용히 대체하지 않는다.
