# 회색지대 평가셋(`gray`) 사전등록

이 문서의 **1–4절은 측정 전에 쓴 것**이고 해시를 테스트가 고정한다. 결과와 '빗나감'은 5절 이후에 덧붙인다. 예상이 틀려도 1–4절은 고치지 않는다.

## 1. 왜 이 셋이 필요한가

지금까지의 평가셋은 두 가지 약점이 있다([LIMITATIONS.md](LIMITATIONS.md) 1절).

1. **회색지대가 거의 없다.** `redteam` 작성자에게 "정책으로 분명히 판정되는 경우만 넣으라"고 했다. 사람 심사자도 갈릴 만한 소재는 일부러 뺐다.
   그래서 독립 라벨러 3명이 72건에서 판정·규칙 모두 일치(κ = 1)했고, 이는 정책이 명확하다는 증거일 수도 같은 모델 계열이 같게 읽는다는 증거일 수도 있었다.
2. **judge 의 오탐을 재기에는 정답 APPROVE 가 적다.** 실호출 측정에서 정답 APPROVE 는 68건이었고 한 건이 1.5%p 였다. 오탐(정상 소재를 건드림)이 기본값(D-14)을 정했는데 그 근거가 작다.

이 셋은 둘을 직접 겨냥한다: 회색지대를 *의도적으로* 넣고(작성자 지시), 정상·정상 유사 소재를 충분히 넣는다.

질문:

- **Q1.** 결정론 파이프라인(`full`)은 회색지대를 포함한 새 셋의 *첫 접촉*에서 어떻게 움직이는가?
- **Q2.** 독립 라벨러 3명은 회색지대에서 얼마나, 어디서 갈리는가? (이전 100% 일치와 대조)
- **Q3.** judge v1(`claude-opus-5-5`, effort `medium`, [JUDGE_LIVE.md](JUDGE_LIVE.md) 와 같은 프롬프트)의 패턴 — 위험 승인 감소와 정상 소재 변경 — 은 새 셋에서도 유지되는가?
- **Q4.** judge v2(정책 조항 *검색*으로 규칙의 정의·예외를 프롬프트에 넣는다)는 v1 대비 정상 소재 변경(오탐)을 줄이면서 위험 승인 감소를 유지하는가?
- **Q5.** 사후 가설(JUDGE_LIVE 6.4절: 오탐 후보의 신뢰도가 낮다)이 **새 셋**에서도 성립하는가?

## 2. 데이터

| 파일 | 내용 |
|---|---|
| `data/gray.jsonl` | 120건(조각 A–J × 12). 독립 작성자 10명이 `POLICY.md` 와 형식 설명만 보고 썼다. 조각마다 clear 3 · normal 3 · gray 6(작성자 지시). `id` = `G-<조각><번호>`. **측정 전에 `MANIFEST.sha256` 로 동결한다.** |
| `data/gray_notes.jsonl` | 작성자가 쓴 노트(왜 이 정답인지, 무엇이 갈릴 수 있는지, 대안 판정 `alt_decision`). 평가에 쓰지 않고 분쟁 분석에만 쓴다. |
| `data/labeler_gray.jsonl` | 독립 라벨러 3명이 *같은* 120건에 정답·태그·id 를 가린 채 붙인 판정·위반(라벨러마다 120건, 조각 3개로 나눠 맡긴다). |

- 작성자·라벨러는 설계자와 **같은 모델 계열**의 별도 컨텍스트 LLM 이다. 사람 심사자가 아니다. 이 한계는 이 셋이 풀지 못한다.
- 정답은 **작성자의 판정**이다(`redteam` 과 같다). 라벨러가 다르게 읽은 소재를 설계자가 고르지 않는다.
- **분쟁(`disputed`)**: 라벨러 3명 중 **2명 이상**의 판정이 작성자 정답과 다르면 그 소재에 `disputed` 태그를 *기계적으로* 붙인다. 판단하지 않는다. 지표는 두 가지로 낸다 — 전체(작성자 정답)와 분쟁 제외.
- 작성자가 `alt_decision` 을 적은 gray 소재는 **관대한 정확도**(정답 또는 대안 판정이면 맞음)를 *따로* 보고한다. 헤드라인 지표는 엄격한(작성자 정답) 정확도다.
- 슬라이스: `clear`/`normal`/`gray`(작성자 태그), `disputed`.

## 3. 지표와 사전 예상

지표 정의는 [EVAL_PLAN.md](EVAL_PLAN.md) 3절과 같다(정확도, 위험 승인율, 정상 오반려, 정상 오보류, 자동 처리율, 규칙 F1). 추가:

- **오탐(judge)**: 정답 APPROVE 소재 중 judge 때문에 판정이 바뀐 비율(JUDGE_LIVE 의 `approve_changed` 와 같다).
- **회수(judge)**: 결정론이 APPROVE 로 놓친 위험 소재(정답 REJECT/REVIEW) 중 judge 때문에 APPROVE 가 아니게 된 비율.
- **검색 재현율@k**(v2): 정답 위반의 규칙 중 검색된 조항에 든 비율. 검색을 안 쓴 v1 은 '모든 규칙 요약'이라 해당 없다.

**사전 예상**(측정 전의 내 믿음이다. 틀려도 고치지 않고 5절 이후에 '빗나감'이라 쓴다):

| # | 예상 | 근거 |
|---|---|---|
| E1 | 결정론 `full` 의 위험 승인율은 **35–60%**(점 추정 48%), 정상 오반려는 ≤ 6%, 정상 오보류(APPROVE→REVIEW)는 10–25%, 정확도는 45–65% | `redteam` 첫 접촉 41.2%, 수정 뒤 27.5%. 이번 셋은 의미상 위반과 경계 소재가 많아 더 높을 것 |
| E2 | 라벨러 판정 일치도(작성자 정답과)는 **70–88%**, 다중 라벨러 κ 0.55–0.82, `disputed` 는 **≥ 8건(≥ 6.7%)** | 회색지대를 의도적으로 넣었다. 이전 셋은 100% 였다 |
| E3 | judge v1: 위험 승인율 상대 감소 **≥ 35%**(점 추정 50%), 오탐 **8–18%**(점 12%) | JUDGE_LIVE 에서 오탐 7.3%. 이번 셋은 정상 유사가 많아 더 높을 것 |
| E4 | judge v2: v1 대비 오탐 상대 감소 **≥ 30%**이고 회수 감소는 v1 대비 **5%p 이내** | 정의·예외를 보여 주면 예외 맥락 오탐이 줄 것. 다만 확신하지 않는다(내가 이 예상이 맞을 확률을 50% 로 본다) |
| E5 | 신뢰도 문턱 θ = **0.65**(JUDGE_LIVE 에서 본 틈의 중간, *이 값은 이 셋을 보기 전에 정한다*)를 v1 에 걸면 오탐 상대 감소 **≥ 50%**이고 회수 감소 ≤ **3%p** | 같은 209건에서 본 사후 가설이다. 새 셋에서 깨질 확률이 더 크다고 본다(성립 확률 40%) |

## 4. 판단 규칙(측정 전에 정한다)

- **R1.** E4 의 *두 조건이 모두* 충족되면 judge v2 를 기본 judge 프롬프트로 채택한다. 하나라도 어긋나면 v1 을 유지하고 v2 는 실험으로만 남긴다.
- **R2.** E5 의 두 조건이 모두 충족되면 `judge_min_confidence = 0.65` 를 기본값으로 채택한다. 아니면 채택하지 않고 가설이 깨졌다고 적는다.
- **R3.** 결정론 첫 접촉에서 정답 APPROVE 소재가 REJECT 되면(정상 오반려 ≥ 1) 원인을 FAILURES 에 적는다. 탐지기는 *첫 접촉 수치를 보존한 뒤에만* 고치며, 고친 뒤 수치에는 '수정 후, holdout 아님'을 단다. 뜻을 돌려 말한 위반을 어휘로 막는 수정은 하지 않는다(D-11).
- **R4.** 분쟁 소재가 20건을 넘으면 정책 문구 모호함의 신호로 [POLICY_GAPS.md](POLICY_GAPS.md) 에 *열림*으로 적는다. 정답은 고치지 않는다.
- **R5.** 어느 구성도 한 번만 잰다. 수치가 마음에 들지 않아 프롬프트·스키마·탐지기를 바꿔 같은 측정을 다시 하지 않는다(다른 설정은 새 사전등록).

## 5. 프로토콜(순서)

1. 작성자 조각 10개를 형식 검사(내용은 고치지 않음)로 통과시켜 합치고, 라벨러 3명이 정답을 못 본 채 라벨링한다. 일치도를 계산하고 `disputed` 를 붙인다.
2. `data/gray.jsonl`·`data/labeler_gray.jsonl` 을 `MANIFEST.sha256` 에 올려 동결한다. **이 문서와 동결을 같은 커밋 전에 올린다.**
3. 결정론 `full` 첫 접촉을 재고 `artifacts/history/gray_first_contact.json` 에 보존한다(E1).
4. judge v2 의 프롬프트·검색을 커밋한 *뒤* 두 구성(v1, v2)을 같은 모델·effort 로 소재당 한 번씩 실호출 녹음한다(비용 상한은 사용자 승인 뒤). 녹음을 한 번만 재생·집계한다(E3·E4).
5. θ 는 녹음의 신뢰도에 후처리로 적용한다(추가 호출 없음)(E5).

## 6. 주장하지 않는 것

실제 광고에서의 정확도, 사람 심사자와의 일치도, 정책의 법적 적합성. 작성자·라벨러·judge 가 모두 같은 모델 계열이라 낙관 쪽 편향이 남는다.
