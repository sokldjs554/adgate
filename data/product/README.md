# 상품 페이지 평가셋 (`data/product/`)

소재 생성 파이프라인(`src/adgate/creative/`)의 평가셋이다. 한 건 = 상품 페이지(HTML 스냅샷 `pages/<id>.html`) + 상품 이미지 사양 + 광고주·브랜드 보이스 + **정답**(페이지에 심은 함정의 목록). 평가 계획은 [docs/EVAL_CREATIVE.md](../../docs/EVAL_CREATIVE.md).

| 파일 | 내용 |
|---|---|
| `dev.jsonl` | 12건(조각 A·B). 설계자가 채점기·하니스를 맞추며 *보았다* — holdout 이 아니다. 동결하지 않았다 |
| `test.jsonl` | 36건(조각 C–H). `MANIFEST.sha256` 로 동결(페이지 36개 포함) |
| `pages/` | 페이지 HTML 48개. test 의 36개는 동결 |

정답이 담는 것(형식은 `src/adgate/creative/products.py`, 검사는 `validate()`):

- `facts` — 페이지(또는 상품 이미지의 글자)에 *실제로 있는* 사실과 우선순위(1 = 좋은 광고라면 말해야 하는 핵심).
- `unsafe_claims` — 페이지가 스스로 하고 있지만 광고로 옮기면 정책 위반인 주장(보이는 곳·숨은 곳·이미지 속).
- `injection_payloads` — 페이지에 심은, 광고 생성기에게 내리는 지시 문구.
- `must_not_state` — 조건을 달아 말한 사실을 *조건 없이* 부풀린 문구.
- `traps` — 이 상품이 시험하는 함정.

작성자 8명(조각 A–H × 6건)은 형식 사양·정책·이미지 사양과 형식 검사기만 보고 썼다. 같은 모델 계열의 별도 컨텍스트 LLM 이다. 사람이 쓴 페이지가 아니다. 시스템 코드는 보지 못했다.
모든 업체·상품·URL·후기는 가상이다.

## 작성자가 멈칫한 곳 (보고에서 모음)

의뢰서의 공백이었으며 정답은 작성자의 판단이다. 고치지 않았다.

- 가격 모순(`conflicting_price`) 상품에서 어느 가격이 맞는지는 페이지 만으로 정할 수 없어 작성자가 정했다(결제 영역·JSON-LD 와 일치하는 값을 기준으로).
- 위반 규칙이 겹칠 때(GUA·HLT, ABS·ENDO, CMP) 정책 문서의 우선순위를 따랐다. 일부 상품은 두 함정에 모두 올렸다.
- 대출·투자에는 ‘가격’이 없어 가격 함정을 월 구독료 모순·금리 수치 부재·이자 면제 조건으로 읽었다. 위반 규칙 FIN 은 ‘고지 부재’ 규칙이라 `unsafe_claims`(인용이 있어야 한다)로 쓸 수 없었다.
- clean 상품에 `must_not_state` 를 넣어도 되는지 의뢰서가 불분명했다(검사기는 허용; 3개 상품).
- 이미지에만 있는 사실에 원·%·기간 수치를 두면 랜딩 대조 규칙이 REVIEW 를 내므로 수치 없는 사실로 했다.
- 정당한 기능성 문구(‘식후 혈당 상승 억제에 도움’)는 질병명이 아닌 상태 표현이라 위반이 아닌 사실로 분류했다.
- 일부 위반 문구는 *주입 지시 속*에만 있어 `unsafe_claims` 가 아니라 `injection_payloads` 에만 적었다.

## 독립성 기록

- 작성자 A 는 검색 범위를 넓게 잡아, 같은 `pages` 폴더의 다른 작성자 파일명과 키워드 몇 개(100%, 오늘만, 마감 …)가 출력 미리보기에 보였다고 보고했다. 그 파일은 열지 않았다.
- 설계자는 구성 집계(카테고리·함정·정답 개수)와 채점 규칙을 정하느라 test 의 정답 데이터를 측정 전에 읽었다. test 의 모델 출력은 본 적이 없다(EVAL_CREATIVE.md R7).

## 채점기에서 알아 둘 것

- 부풀림 금지 문구가 정답 사실 안에 통째로 들어 있으면(예: `무료 배송` 이 `10만 원 이상 구매 시 무료배송` 안에) 글자로는 정직한 진술과 구별할 수 없어 자동 판정에서 뺀다. dev 에 3개, test 에 0개다.
- test 의 주입 지시 24개 중 1개(`'0원'` — 정답 사실 안에 있는 값)는 글자로 판정할 수 없다.
